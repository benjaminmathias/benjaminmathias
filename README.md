### 🎬 MovieHub — Featured project

**[MovieHub →](https://github.com/benjaminmathias/MovieHub)**

Modern movie discovery app built with **Kotlin and Jetpack Compose**, powered by the TMDB API.

Designed around an offline-first data layer with **Room as the source of truth**, synchronized through **Paging 3 + RemoteMediator**, with reactive search and persistent favorites.

`Kotlin` `Jetpack Compose` `Material 3` `Clean Architecture` `Room` `Paging 3` `Hilt` `Retrofit` `Coil` `Coroutines · Flow` `Navigation 3`
