## 🚀 Featured projects

### 🎬 [MovieHub](https://github.com/benjaminmathias/MovieHub)
`Kotlin` · `Jetpack Compose` · `Room` · `Paging 3` · `Navigation 3`

Movie discovery app built on the TMDB API.
- **Offline-first feeds:** Room is the single source of truth, synced from TMDB through `RemoteMediator`.
- **Local library:** favorites, watchlist and watched states survive refreshes and update optimistically, with rollback on failure.
- **Pragmatic layering:** UI / domain / data split, CI on GitHub Actions.

### 🏠 [RealEstateManager](https://github.com/benjaminmathias/RealEstateManager)
`Kotlin` · `Android Views` · `MVVM` · `Hilt` · `Room`

Property management app for real-estate agents.
- Create, edit, search and track listings, stored locally with Room.
- Google Maps view of listings and multi-criteria search.
- Adaptive phone and tablet layouts, tested with JUnit, Robolectric and Espresso.

### 🍽️ [Go4Lunch](https://github.com/benjaminmathias/Go4Lunch)
`Java` · `Firebase` · `RxJava` · `Google Places`

Team lunch app: find nearby restaurants and see where your coworkers are eating.
- Restaurant search on a map with the Google Places API.
- Firebase Auth sign-in and real-time chat backed by Firestore.
